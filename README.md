# Between You & Me — Website

A responsive static website for the personal brand Between You & Me.

## Publish free with GitHub Pages

1. Create/sign in to a free GitHub account at https://github.com.
2. Click **New repository**. Name it `between-you-and-me` (or another name).
3. Set the repository to **Public**, then create it.
4. Upload `index.html` and `styles.css` from this folder to the repository's main/root branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. GitHub will display your published website URL in the Pages section. It will usually look like:
   `https://YOUR-USERNAME.github.io/between-you-and-me/`

Replace `YOUR-USERNAME` with your actual GitHub username. The exact URL is only known after you create the repository and publish it.

## Editing

Edit the wording in `index.html` and visual styles in `styles.css`. This is a static informational website; it does not collect personal health information or provide medical advice.
